## Purpose

This stage tests only the first frozen gate: whether the pole-to-polygon construction is mathematically well-defined for arbitrary base cardinality `N >= 3` and whether the existing tetrahedral Bloch-ball construction admits a non-ad-hoc generalization.

The frozen v0.1 prediction is not modified by this document.

## 1. General pole-to-polygon family

Fix a polar apex

\[
p=(0,0,1).
\]

For any integer

\[
N\ge 3,
\]

choose a base latitude `c_N` with

\[
-1<c_N<1,
\]

and define

\[
r_N=\sqrt{1-c_N^2}.
\]

The regular `N`-point base on the unit Bloch sphere is

\[
b_k^{(N)}=
\left(
 r_N\cos\frac{2\pi k}{N},
 r_N\sin\frac{2\pi k}{N},
 c_N
\right),
\qquad k=0,\ldots,N-1.
\]

Therefore the pole-to-regular-polygon family is mathematically well-defined for every finite `N >= 3` once a latitude rule `c_N` is specified.

### Stage-1 result A

`PASS_EXISTENCE_CONDITIONAL_ON_LATITUDE_RULE`

There is no topological obstruction to `N=3,4,5,...` as a family of pole-connected regular polygonal bases inside/on the Bloch ball.

This does not yet derive the excitation rule or the latitude rule.

## 2. Recovery of the canonical tetrahedron

For `N=3`, the canonical TIR tetrahedron uses

\[
c_3=-\frac13,
\qquad
r_3=\frac{2\sqrt2}{3}.
\]

The three base vertices generated by the formula above reproduce the regular tetrahedral base up to an in-plane rotation.

Thus the frozen polygonal family contains the existing TIR tetrahedral frame as its `N=3` member.

### Stage-1 result B

`PASS_TETRAHEDRAL_RECOVERY`

## 3. Strong equal-edge continuation test

The original tetrahedron has a stronger property than merely being a pole plus regular base: all six chordal edges are equal.

Test whether that same property can be continued to arbitrary `N` while keeping the apex and all base vertices on the unit sphere.

The squared apex-to-base chord is

\[
\ell_{pB}^2=2(1-c_N).
\]

The squared chord between adjacent base vertices is

\[
\ell_{BB}^2
=2(1-c_N^2)
\left(1-\cos\frac{2\pi}{N}\right).
\]

Imposing

\[
\ell_{pB}=\ell_{BB}
\]

gives, for the nontrivial branch `c_N != 1`,

\[
1=(1+c_N)\left(1-\cos\frac{2\pi}{N}\right),
\]

hence

\[
\boxed{
 c_N=
 \frac{\cos(2\pi/N)}{1-\cos(2\pi/N)}
 }.
\]

This produces

| N | c_N | result |
|---:|---:|---|
| 3 | -1/3 | nondegenerate; canonical tetrahedron |
| 4 | 0 | nondegenerate square-base continuation |
| 5 | 1/sqrt(5) approx 0.4472136 | nondegenerate pentagonal continuation |
| 6 | 1 | degenerate: base collapses to apex latitude |
| >6 | >1 | impossible on the unit sphere |

### Stage-1 result C

`FAIL_INFINITE_STRICT_EQUAL_EDGE_CONTINUATION`

The frozen hypothesis does **not** yield an infinite excitation ladder if every level is required to preserve the tetrahedron's full equal-edge chordal condition on the unit Bloch sphere.

However, the frozen prediction did not require this extra condition. The general pole-to-polygon family remains mathematically admissible for arbitrary `N` if the excitation changes latitude, edge classes, radial depth, or an equivalent geometric invariant.

This distinction is retained as a validation result and is not used to rewrite v0.1.

## 4. Poincare projection for arbitrary N

Let positive weights be

\[
w=(w_0,w_1,\ldots,w_N),\qquad w_i>0,
\]

where `w_0` belongs to the polar apex and `w_1,...,w_N` to the polygonal base.

Define the Bloch-ball convex point

\[
X_N(w)=
\frac{w_0p+\sum_{k=0}^{N-1}w_{k+1}b_k^{(N)}}
{\sum_{j=0}^{N}w_j}.
\]

Because this is a convex combination of unit-ball points,

\[
|X_N(w)|\le 1,
\]

with strict interior placement for positive noncollapsed mixtures.

The existing TIR Klein-to-Poincare map therefore generalizes directly:

\[
Y_N=
\frac{X_N}{1+\sqrt{1-|X_N|^2}}.
\]

Projection onto the base plane gives

\[
z_N=\langle Y_N,e_1\rangle+i\langle Y_N,e_2\rangle,
\qquad |z_N|<1.
\]

Thus every nondegenerate finite polygonal state has a well-defined Poincare-disk image.

`PASS_ARBITRARY_N_POINCARE_PROJECTION`

The existing TIR dependency

\[
T_4\to\mathbb D_T
\]

admits the structural generalization

\[
P\star B_N\to\mathbb D_N
\]

for arbitrary finite `N >= 3`, provided a nondegenerate base geometry is supplied.

## 5. What Stage 1 establishes

The following are now mathematically supported:

1. the canonical tetrahedron is exactly the `N=3` member of a regular pole-to-polygon family;
2. a square-base `N=4` state exists naturally on the Bloch sphere;
3. arbitrary finite `N` regular bases can be constructed with an independent latitude/depth rule;
4. those states admit the same convex Bloch/Klein-to-Poincare projection structure used by TIR;
5. the strongest equal-edge extension has a sharp geometric cutoff at `N=5` and therefore cannot itself generate the frozen infinite ladder.

## 6. Unresolved gate

The central unresolved mathematical question is now narrower:

\[
\boxed{
\text{What TIR-native invariant determines }c_N\text{ or radial depth as }N\to N+1?
}
\]

An infinite excitation ladder requires a derived rule that changes at least one of:

- base latitude / Bloch depth;
- apex-to-base versus base-to-base edge ratio;
- hyperbolic radius after Poincare projection;
- phase/holonomy associated with the polygonal cycle.

No such rule is selected in Stage 1.

## Verdict

`STAGE_1_PARTIAL_PASS_WITH_STRONG_CONSTRAINT_DISCOVERY`

The arbitrary-N polygonal/Poincare family is mathematically well-defined and contains the canonical tetrahedron. The naive strict equal-edge continuation is finite (`N=3,4,5`) rather than infinite. The frozen infinite-excitation prediction remains open and moves to Stage 2: derive the excitation invariant from existing TIR geometry without fitting external observables.
